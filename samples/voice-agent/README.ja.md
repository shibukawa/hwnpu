# voice-agent

[English](README.md) · [サンプルの一覧](../README.ja.md)

名前で呼ぶと、声で答える小さな音声アシスタントです。呼び名は「コダマ」です (「コダマ、今何時？」「ねえコダマ、明日の天気は？」)。できるのは、時刻と日付、タイマー、天気 ([Open-Meteo](https://open-meteo.com))、ニュースの見出し (NHK の RSS)、Wikipedia での調べものです。それ以外の質問には、チャットのモデルが自分で答えます。

```
mic → vad → transcribe → 名前? → ショートカット (時刻、タイマー) ──────→ speech → speaker
                               └→ チャットのモデル ⇄ 道具 → 文ごとに ──┘
```

NPU で動くモデルは 3 つです。Whisper large-v3-turbo (書き起こし)、LFM3-1.7B (道具を呼ぶチャット)、Supertonic 3 (読み上げ、OpenRAIL-M) です。

汎用の部分はライブラリにあります。道具を呼ぶ会話は [`ai/agent`](../../ai/agent)、聞き取りと読み上げと早く答える工夫は [`ai/agent/voice`](../../ai/agent/voice) です。このサンプルが持つのは、システムプロンプトとユーザーのこと (prompt.go)、道具 (tools.go、timers.go)、モデルを通さずに答える頼み (shortcut.go)、コマンド (main.go) だけです。ほかの声のアシスタントも、道具とプロンプトを替えれば同じパッケージで作れます。

## 動かし方

```bash
cd samples
go run ./voice-agent models prepare          # 最初に 1 回: ダウンロード (約 7.5 GB)、変換、コンパイル
go run ./voice-agent                         # マイクで聞く。Ctrl-C で終わる
go run ./voice-agent --place 大阪 --user 太郎さん --about "経済のニュースに関心がある"
go run ./voice-agent run talk.wav            # 録音を、マイクと同じ速さで聞かせる
go run ./voice-agent ask 明日の天気は？       # 1 つの質問を文字で渡し、声で答える
go run ./voice-agent ask --text 今日のニュース # 声を出さずに文字で答える (チャットのモデルだけを読み込む)
```

話しかけ方:

- 「コダマ、〜」で頼みます。「コダマ」とだけ言うと、チャイムを鳴らして次のひとことを待ちます
- 答えたあとの 8 秒 (`--follow`) は、名前なしで続けて頼めます
- 「3分のタイマー」「ラーメンのタイマーを止めて」「タイマーあと何分？」「今何時？」「会話をリセットして」は、モデルを通さずにすぐ答えます (`--no-shortcuts` でモデルに回す)
- 会話は 5 分 (`--reset`) 頼まれなければ忘れます。覚えておくのは前の数ターン (`--history`) だけなので、プロンプトはいつも短く、速く読めます

ユーザーについては、起動時に次を渡せます。どれもシステムプロンプトに入り、起動している間は変わらないので、モデルのキャッシュから読まれます。

| オプション | 中身 |
|---|---|
| `--place` | 住んでいる所 (市か都道府県)。天気で場所を言われなかったときに使う。既定は東京 |
| `--user` | ユーザーの呼び方 |
| `--about` | ほかに知っておいてほしいこと (家族、仕事、関心のあるニュースなど) を 1、2 文で |

## なるべく早く答えるための工夫

チャットなら入力が終わってから処理すれば足りますが、声では話し終わってから最初の音が出るまでの時間が大事です。`ai/agent/voice` の `Listener` でやっていることは次のとおりです。

1. **話の切れ目で先に書き起こす。** VAD が発話の終わりと決めるのは 700 ms の無音のあとですが、250 ms (`--pause`) 黙った時点で、そこまでを Whisper にかけ始めます。そのあと話が続かなければ、その書き起こしをそのまま使います。Whisper の時間の大半が、無音を待つ間に隠れます
2. **モデルも先に走らせる。** その書き起こしでチャットのモデルを始めます (`--speculate`、既定でオン)。発話の終わりが確定するまでは声に出さず、道具も実行しません。話が続いたら取り消して、会話は元のままにします
3. **モデルの要らないものはモデルを通さない。** 時刻、日付、タイマーは規則で答えます
4. **答えは区切って読み上げる。** 答えの文はチャットモデルから少しずつ出てくるので、最初の区切りは読点のところで短く切り、すぐに鳴らします。Supertonic 3 は Neural Engine で実時間の約 80 倍で読み上げる (1 文に 0.1 秒以下) ので、文を作る時間はほとんど待ちになりません
5. **決まった言葉は作っておく。** 「ちょっと待ってね」(ネットワークを使う道具の前に言う) などは起動時に一度だけ作り、ディスクに残します (`~/Library/Caches/hwnpu/voice-agent/phrases`)。名前だけで呼ばれたときのチャイムとタイマーの音は合成しません。タイマーの「〜の時間です」は、セットした時点で作っておきます
6. **システムプロンプトを先に読んでおく。** 起動時とリセットのあとに、システムプロンプトと道具の宣言をモデルのキャッシュに読み込みます

ログには「発話が終わってから何秒で書き起こしたか」と「答えの最初の音が何秒後に出たか」を出すので、オプションを変えたときの違いを確かめられます。

## 限界

- **読み上げのライセンス。** Supertonic 3 は OpenRAIL-M です。使い方の制限 (モデルカードの Use Restrictions) があり、派生物にも引き継がれます
- **自分の声を聞く。** 既定では、答えている間 (と直後の 0.3 秒) はマイクを聞きません。`--barge-in` を付けると答えている間も聞き、名前を呼ぶと止まります。ただしヘッドホンでないと自分の声を拾い、その書き起こしの分だけ読み上げが遅くなります
- **呼び名の判定は書き起こしの文字で行う。** 専用のウェイクワードのモデルではないので、呼ばれていない発話も、聞こえたものは全部 Whisper にかけます
- **天気とニュースは外のサービスを使う。** 天気の場所は Open-Meteo の地名検索で探し (市、都、府、県を付けて探し、人口がいちばん多い所を選ぶ)、ニュースは `--feed` の RSS から取ります

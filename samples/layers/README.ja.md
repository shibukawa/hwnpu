# layers

[English](README.md) · [サンプルの一覧](../README.ja.md)

絵を深度で層に分け、各層が隠していた部分を描き足して、Photoshop の文書 (PSD) に書きます。文書の中で層を動かしたり、拡大したり、消したりしても、その裏に絵があります。

```
絵 → 深度 → 一番手前の層を切り出す → 1 色で塗る → 裏を描く
 ↑                                                |
 └────────────── その層のない絵 ←─────────────────┘
```

一番手前の層を切り出し、その形を 1 色で塗って、画像のモデルにそこの背景を描かせます (FLUX.2 klein の編集)。描いた絵の深度から次の層を切り、一番奥まで続けます (一番奥の層はそのまま)。2 つのモデルは交互に動き、片方を頼む前にもう片方を下ろすので、両方が一度にメモリに載らなくて構いません。

## 動かし方

```bash
cd samples
go run ./layers models prepare                   # 最初にモデルのダウンロード、変換、コンパイル (済むまでコマンドは動きません)
go run ./layers plan picture.png                 # 切る場所だけ: 層ごとに色をつけた絵 (描かない)
go run ./layers split picture.png -o picture.psd       # 3 層に分ける
go run ./layers split picture.png --layers 4 --png parts/
```

| オプション | 何をするか |
|---|---|
| `--layers N` | 層の数、2〜8 (既定 3)。切る場所は深度から求める |
| `--cuts 0.3,0.7` | 代わりにこの近さで切る (0 が一番奥、1 が一番手前) |
| `--png DIR` | 層 (`layer-N.png`)、その近さ (`near-N.png`、16 ビット)、モデルに頼んだ絵と描いた絵も書く。`parallax show DIR` がこれを見せる |
| `--hint "no people"` | 裏を描く頼みに足す言葉 |
| `--tries 3` | モデルが層の形を残したら (平らな色や影)、別の種で描き直す |
| `--seed`、`--edge`、`--clean`、`--far` | 種、層が切った所からはみ出す幅、その先で描いた絵を使う幅、深度の奥の広げ方 |

## ダウンロード

| モデル | Apple | AMD |
|---|---|---|
| Depth Anything 3 Base (深度) | 0.5 GB | 2.4 GB |
| FLUX.2 klein 4B (層が隠していた部分) | 16 GB | 12.5 GB |
| **合計** | **16.5 GB** | **14.9 GB** |

16 GB の機械の場合です。この機械の量は `layers models` が出します。Mac では FLUX.2 klein はチェックポイントで、ここで 2 つの書き出し (7.5 GB と、編集のプログラムの 4.1 GB) に変換し、どちらもその横に残ります。

## 要るもの

- モデル: Depth Anything 3 Base (0.5 GB) と FLUX.2 klein 4B。
- 1 層の描き足し: AMD の NPU で 1024×1024 が約 1 分 (3 層で 2 回描いて 2〜3 分半)、M3 で 512×512 が 39 秒、1024×1024 が 89 秒。
- Apple の Neural Engine で参照から描くには、FLUX.2 klein の編集のプログラムが要ります。チェックポイント (16 GB のダウンロード) から変換し、最初の編集でコンパイルします (最大 1 時間ほど。prebuilt でなくす予定)。
- 絵はモデルの大きさのうち形の一番近いもので描き、伸ばし戻します。PSD は層が文書と同じ大きさの 8 ビット RGB です。

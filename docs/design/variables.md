# Variables: BonsaiAI's environment

[日本語](variables.ja.md)

State: sorted out on 2026-11-22. BonsaiAI's processes read four kinds of variables; the developers'
switches and the tests' are each one family with one way of naming, so that what a variable is
for can be told from its name.

| Kind | Names | Read by |
|---|---|---|
| Settings | `BONSAIAI_CACHE*`, `BONSAIAI_MODEL_SOURCE*`, `BONSAIAI_MODEL_HUGGING_FACE`, `BONSAIAI_MODELS`, `BONSAIAI_MODEL_ALLOWLIST`, `BONSAIAI_ACCEPT_LICENSE`, `BONSAIAI_MEMORY`, `BONSAIAI_BACKEND`, `BONSAIAI_DEVICE`, `BONSAIAI_COREAI_UNITS`, `BONSAIAI_COREML_UNITS`, `BONSAIAI_COREAI_PREBUILT`, `BONSAIAI_MOE_WIRE`, `BONSAIAI_WEBDAV_*`, `BONSAIAI_HF_CLIENT_ID`, `BONSAIAI_DAEMON*`, `BONSAIAI_JOBS`, `BONSAIAI_PROFILE`, `BONSAIAI_ENERGY`, `BONSAIAI_NO_RUN_LOG` | The programs, from the environment and the `.env` files (`internal/envfile`); with bonsaiaid, whose each one is:  [bonsaiaid](bonsaiaid.md#settings) |
| The machine's libraries | `BONSAIAI_ONNXRUNTIME`, `BONSAIAI_OV_PYTHON`, `BONSAIAI_XRTSHIM`, `BONSAIAI_XRT_CORE`, `BONSAIAI_ZE_LOADER`, `BONSAIAI_IRON_ENV` | The backends; bonsaiaid's |
| The developers' switches | `BONSAIAI_DEV=KEY[=VALUE],...` | `internal/dev`; a process's own, never sent to bonsaiaid |
| The tests' | `BONSAIAI_TEST_<GROUP>_<ROLE>`, `BONSAIAI_TEST_NPU` | `go test` only |

Not here: the Python tools' own switches (`tools/amd/iron_*.py`: `BONSAIAI_LFM3_FUSED_*`,
`BONSAIAI_Q_CORES`, ...), which an export reads, and `bonsaiai-dev powerbench`'s `BONSAIAI_POWERMETRICS`
(a command line). Removed: `BONSAIAI_NPU_LOCK` (the Neural Engine's lock is never skipped: several
apps share the Neural Engine through bonsaiaid).

## The developers' switches: BONSAIAI_DEV

Experiments, measurements and traces: a conversion's other form, a policy off, a trace written.
None changes what a user gets by default, and none is a setting of the user's.

- Items separated by commas; an item is a key (on) or `KEY=VALUE`; a key's group goes before a
  dot (`moe.`, `iron.`, `coreai.`, `ailower.`, `mxfp4.`, `draft.`). `BONSAIAI_DEV=moe.time,moe.prefetch=0,ailower.trace`.
- `internal/dev.Keys` lists every key with what it does; `TestKeysUsed` checks that every key the
  code reads is there and every key there is read. An unknown key is told once on standard error.
- It is read at each call (`dev.Get`, `On`, `IsOff`, `Value`, `Int`), so that a test's
  `t.Setenv` takes.
- bonsaiaid does not take a client's: an experiment runs in the developer's own process
  (`BONSAIAI_DAEMON=off`; the default is on), with the Neural Engine's lock as before.

## The tests' variables

`BONSAIAI_TEST_<GROUP>_<ROLE>`. The group is the model or the part (`LFM3`, `SFX`, `MRT`, `IRON`,
`OCR`, ...); the role says what the value is:

| Role | The value |
|---|---|
| `_DIR` | A model's directory of its checkpoint (Hugging Face's layout); `_CKPT_DIR` a derived checkpoint |
| `_EXPORT` | A converted export or package |
| `_FILE` | One input file: a model file (ONNX, TFLite, ELF), a tokenizer, a picture, a sound |
| `_REF` | A reference written by `tools/ref` (Python); `_TOKENS_REF` a tokenizer's, `_EMBED_REF` an embedding model's, `_ENCODER_REF` an encoder's |
| `_OUT` | Where a test writes what it made |
| anything else | A parameter of the test (`_FORMAT`, `_QUANT`, `_LAYERS`, `_PROMPT`, ...) |

- **`BONSAIAI_TEST_NPU`** (set: on) runs the tests that use the NPU, which the variables of their
  inputs no longer turn on alone. They wait for the Neural Engine's lock and may convert, so
  `go test ./...` without it never touches the NPU.
- **`-short`** skips the tests that are only slow on the CPU (`TestPagedCheckpoint`).
- A test that needs a model's files skips, saying which variables it needs, when they are not
  set.
- Tests run in their own process and never through bonsaiaid, with the Neural Engine's lock as
  before; `BONSAIAI_CACHE` is a temporary root unless set (`internal/cache`).

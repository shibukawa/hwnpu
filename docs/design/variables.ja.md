# 変数: hwnpu の環境

[English](variables.md)

状態: 2026-11-22 に整理した。hwnpu のプロセスが読む変数は 4 種類。開発者のスイッチとテストの変数はそれぞれ 1 つの族と 1 つの
名付け方にまとめ、名前から何のための変数かが分かるようにした。

| 種類 | 名前 | 読むもの |
|---|---|---|
| 設定 | `HWNPU_CACHE*`、`HWNPU_MODEL_SOURCE*`、`HWNPU_MODEL_HUGGING_FACE`、`HWNPU_MODELS`、`HWNPU_MODEL_ALLOWLIST`、`HWNPU_ACCEPT_LICENSE`、`HWNPU_MEMORY`、`HWNPU_BACKEND`、`HWNPU_DEVICE`、`HWNPU_COREAI_UNITS`、`HWNPU_COREML_UNITS`、`HWNPU_COREAI_PREBUILT`、`HWNPU_MOE_WIRE`、`HWNPU_WEBDAV_*`、`HWNPU_HF_CLIENT_ID`、`HWNPU_DAEMON*`、`HWNPU_JOBS`、`HWNPU_PROFILE`、`HWNPU_ENERGY`、`HWNPU_NO_RUN_LOG` | プログラムが環境と `.env` (`internal/envfile`) から。hwnpud があるときにどれが誰のものかは [hwnpud](hwnpud.ja.md#設定) |
| 機械のライブラリ | `HWNPU_ONNXRUNTIME`、`HWNPU_OV_PYTHON`、`HWNPU_XRTSHIM`、`HWNPU_XRT_CORE`、`HWNPU_ZE_LOADER`、`HWNPU_IRON_ENV` | バックエンド。hwnpud のもの |
| 開発者のスイッチ | `HWNPU_DEV=KEY[=VALUE],...` | `internal/dev`。プロセス自身のもので、hwnpud には送らない |
| テストのもの | `HWNPU_TEST_<群>_<役>`、`HWNPU_TEST_NPU` | `go test` だけ |

ここにないもの: `hwnpu-dev powerbench` の `HWNPU_POWERMETRICS` (コマンド行)。Python の道具の測定用のスイッチ
(`tools/amd/iron_*.py` の `HWNPU_LFM3_FUSED_*`、`HWNPU_Q_CORES` など) は 2026-11-26 になくした。書き出しは既定だった
道だけを通る。人が設定するものは `HWNPU_EXPORT_STEPS` (診断の出力、[AMD の LLM](amd-llm.ja.md)) だけが残る
(`GPTOSS_EXPERT_PLACES` と `GPTOSS_HOST_ROUTE` は `iron_export_lm.py` がオプションから自分で設定する)。なくしたもの: `HWNPU_NPU_LOCK` (Neural Engine の
ロックは飛ばさない。複数のアプリは hwnpud を通して Neural Engine を分け合う)。

## 開発者のスイッチ: HWNPU_DEV

実験、計測、トレース: 変換の別の形、方針を切る、トレースを書く。どれも利用者が既定で得るものを変えず、利用者の設定でもない。

- 項目はカンマで区切る。項目は鍵だけ (入) か `KEY=VALUE`。鍵の群はドットの前 (`moe.`、`iron.`、`coreai.`、`ailower.`、
  `mxfp4.`、`draft.`)。`HWNPU_DEV=moe.time,moe.prefetch=0,ailower.trace`
- `internal/dev.Keys` が全部の鍵と働きを持つ。`TestKeysUsed` は、コードが読む鍵が全部そこにあり、そこにある鍵が全部読まれて
  いることを確かめる。知らない鍵は標準エラーに一度だけ出す
- 呼ぶたびに読む (`dev.Get`、`On`、`IsOff`、`Value`、`Int`)。テストの `t.Setenv` が効くように
- hwnpud はクライアントのものを取らない: 実験は開発者自身のプロセスで動かす (`HWNPU_DAEMON=off`。既定は on)。
  Neural Engine のロックは今までどおり

## テストの変数

`HWNPU_TEST_<群>_<役>`。群はモデルか部品 (`LFM3`、`SFX`、`MRT`、`IRON`、`OCR` など)。役は値が何かを言う:

| 役 | 値 |
|---|---|
| `_DIR` | モデルのチェックポイントのフォルダ (Hugging Face の並び)。`_CKPT_DIR` は派生したチェックポイント |
| `_EXPORT` | 変換した書き出しかパッケージ |
| `_FILE` | 入力のファイル 1 つ: モデルのファイル (ONNX、TFLite、ELF)、トークナイザー、画像、音 |
| `_REF` | `tools/ref` (Python) が書いた参照。`_TOKENS_REF` はトークナイザーの、`_EMBED_REF` は埋め込みモデルの、`_ENCODER_REF` はエンコーダーの |
| `_OUT` | テストが作ったものを書く場所 |
| それ以外 | テストのパラメータ (`_FORMAT`、`_QUANT`、`_LAYERS`、`_PROMPT` など) |

- **`HWNPU_TEST_NPU`** (設定で入) は NPU を使うテストを走らせる。入力の変数だけではもう走らない。Neural Engine のロックを
  待ち、変換もするので、これなしの `go test ./...` は NPU に触れない
- **`-short`** は CPU で遅いだけのテストを飛ばす (`TestPagedCheckpoint`)
- モデルのファイルが要るテストは、要る変数がなければ、どれが要るかを言って飛ばす
- テストは自分のプロセスで動き、hwnpud を通らない。Neural Engine のロックは今までどおり。`HWNPU_CACHE` は設定しなければ
  一時の根 (`internal/cache`)

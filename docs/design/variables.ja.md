# 変数: BonsaiAI の環境

[English](variables.md)

状態: 2026-11-22 に整理した。BonsaiAI のプロセスが読む変数は 4 種類。開発者のスイッチとテストの変数はそれぞれ 1 つの族と 1 つの
名付け方にまとめ、名前から何のための変数かが分かるようにした。

| 種類 | 名前 | 読むもの |
|---|---|---|
| 設定 | `BONSAIAI_CACHE*`、`BONSAIAI_MODEL_SOURCE*`、`BONSAIAI_MODEL_HUGGING_FACE`、`BONSAIAI_MODELS`、`BONSAIAI_MODEL_ALLOWLIST`、`BONSAIAI_ACCEPT_LICENSE`、`BONSAIAI_MEMORY`、`BONSAIAI_BACKEND`、`BONSAIAI_DEVICE`、`BONSAIAI_COREAI_UNITS`、`BONSAIAI_COREML_UNITS`、`BONSAIAI_COREAI_PREBUILT`、`BONSAIAI_MOE_WIRE`、`BONSAIAI_WEBDAV_*`、`BONSAIAI_HF_CLIENT_ID`、`BONSAIAI_DAEMON*`、`BONSAIAI_JOBS`、`BONSAIAI_PROFILE`、`BONSAIAI_ENERGY`、`BONSAIAI_NO_RUN_LOG` | プログラムが環境と `.env` (`internal/envfile`) から。bonsaiaid があるときにどれが誰のものかは [bonsaiaid](bonsaiaid.ja.md#設定) |
| 機械のライブラリ | `BONSAIAI_ONNXRUNTIME`、`BONSAIAI_OV_PYTHON`、`BONSAIAI_XRTSHIM`、`BONSAIAI_XRT_CORE`、`BONSAIAI_ZE_LOADER`、`BONSAIAI_IRON_ENV` | バックエンド。bonsaiaid のもの |
| 開発者のスイッチ | `BONSAIAI_DEV=KEY[=VALUE],...` | `internal/dev`。プロセス自身のもので、bonsaiaid には送らない |
| テストのもの | `BONSAIAI_TEST_<群>_<役>`、`BONSAIAI_TEST_NPU` | `go test` だけ |

ここにないもの: Python の道具のスイッチ (`tools/amd/iron_*.py` の `BONSAIAI_LFM3_FUSED_*`、`BONSAIAI_Q_CORES` など。書き出しが
読む) と、`bonsaiai-dev powerbench` の `BONSAIAI_POWERMETRICS` (コマンド行)。なくしたもの: `BONSAIAI_NPU_LOCK` (Neural Engine の
ロックは飛ばさない。複数のアプリは bonsaiaid を通して Neural Engine を分け合う)。

## 開発者のスイッチ: BONSAIAI_DEV

実験、計測、トレース: 変換の別の形、方針を切る、トレースを書く。どれも利用者が既定で得るものを変えず、利用者の設定でもない。

- 項目はカンマで区切る。項目は鍵だけ (入) か `KEY=VALUE`。鍵の群はドットの前 (`moe.`、`iron.`、`coreai.`、`ailower.`、
  `mxfp4.`、`draft.`)。`BONSAIAI_DEV=moe.time,moe.prefetch=0,ailower.trace`
- `internal/dev.Keys` が全部の鍵と働きを持つ。`TestKeysUsed` は、コードが読む鍵が全部そこにあり、そこにある鍵が全部読まれて
  いることを確かめる。知らない鍵は標準エラーに一度だけ出す
- 呼ぶたびに読む (`dev.Get`、`On`、`IsOff`、`Value`、`Int`)。テストの `t.Setenv` が効くように
- bonsaiaid はクライアントのものを取らない: 実験は開発者自身のプロセスで動かす (`BONSAIAI_DAEMON=off`。既定は on)。
  Neural Engine のロックは今までどおり

## テストの変数

`BONSAIAI_TEST_<群>_<役>`。群はモデルか部品 (`LFM3`、`SFX`、`MRT`、`IRON`、`OCR` など)。役は値が何かを言う:

| 役 | 値 |
|---|---|
| `_DIR` | モデルのチェックポイントのフォルダ (Hugging Face の並び)。`_CKPT_DIR` は派生したチェックポイント |
| `_EXPORT` | 変換した書き出しかパッケージ |
| `_FILE` | 入力のファイル 1 つ: モデルのファイル (ONNX、TFLite、ELF)、トークナイザー、画像、音 |
| `_REF` | `tools/ref` (Python) が書いた参照。`_TOKENS_REF` はトークナイザーの、`_EMBED_REF` は埋め込みモデルの、`_ENCODER_REF` はエンコーダーの |
| `_OUT` | テストが作ったものを書く場所 |
| それ以外 | テストのパラメータ (`_FORMAT`、`_QUANT`、`_LAYERS`、`_PROMPT` など) |

- **`BONSAIAI_TEST_NPU`** (設定で入) は NPU を使うテストを走らせる。入力の変数だけではもう走らない。Neural Engine のロックを
  待ち、変換もするので、これなしの `go test ./...` は NPU に触れない
- **`-short`** は CPU で遅いだけのテストを飛ばす (`TestPagedCheckpoint`)
- モデルのファイルが要るテストは、要る変数がなければ、どれが要るかを言って飛ばす
- テストは自分のプロセスで動き、bonsaiaid を通らない。Neural Engine のロックは今までどおり。`BONSAIAI_CACHE` は設定しなければ
  一時の根 (`internal/cache`)
